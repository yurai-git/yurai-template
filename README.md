# Yurai Template

Installs Yurai's template.

## Installation

```bash
npm install -g @yurai/yurai-template
```

```bash
yarn global add @yurai/yurai-template
```

```bash
pnpm add -g @yurai/yurai-template
```

```bash
bun add -g @yurai/yurai-template
```

## Commands

### `yurai-template`

Installs dependencies and sets up VS Code settings, VS Code recommended
extensions, `eslint.config.ts`, and scripts in `package.json`.

#### Options

##### `--version`, `-v`

Output the version number and exit.
